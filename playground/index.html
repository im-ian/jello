jello

누른 자리가 말랑하게 들어가고, 놓으면 출렁이는 UI 피드백 라이브러리.

‘동작 줄이기’가 켜져 있어서 움직임 대신 투명도로 반응해요.

누른 자리가 오목하게 들어가요. 꾹 누르고 있다가 놓아 보세요.

data-jello="firm | gentle | wobbly | bouncy"

네 가지 탄력

%는 손을 뗀 뒤 반대쪽으로 튀어 오르는 정도예요.

firm

돈이 오가는 버튼처럼 진지한 곳. 단단하게 눌리고 거의 튀지 않아요.

gentle

평범한 버튼. 한 번 부드럽게 늘어났다 멈춰요.

wobbly기본값

젤리답게 두 번 출렁여요.

bouncy

좋아요나 스티커처럼 노는 버튼. 서너 번 흔들려요.

컴포넌트

상자에 data-jello를 붙이면 안의 컨트롤이 종류에 맞게 반응해요. 네이티브 요소와 ARIA 상태를 그대로 쓰고, 항목마다 jello가 무엇을 보고 반응하는지 적어 뒀어요. 왼쪽 목록도 세로 탭이라, 고른 자리로 판이 미끄러져 와요.

카드

누른 자리 중심 · data-jello-pivot

모서리를 눌러 보세요 누른 점을 기준으로 찌그러지고 그 자리가 들어가요.

색 · 파일

input[type=color] · input[type=file]

둘 다 고르는 창을 띄우는 버튼이라, 글자를 치는 입력칸이 아니라 눌리는 쪽으로 반응해요. 포커스 부풂이나 타이핑 흔들림은 없어요.

폼 필드

focus · input · invalid · select change

이메일을 비우고 가입하기 → 흔들림. 탭 키로 이동 → 살짝 부풂. 맛을 바꾸면 선택칸이 통통 튀어요.

스테퍼

input[type=number]

값이 올라가면 위로 늘어나고, 내려가면 눌려 앉아요. 숫자를 직접 고쳐도, 위아래 화살표를 눌러도 같아요. 꾹 눌러 빠르게 올리면 한 칸마다가 아니라 맥박처럼 띄엄띄엄 튀어요.

커스텀 스테퍼

[role=spinbutton] · aria-valuenow

2인분

앱은 aria-valuenow만 바꿔요. 숫자가 어느 쪽으로 움직였는지는 jello가 속성 변화에서 읽어요. 포커스 두고 위아래 화살표도 돼요.

검색

[role=combobox] · [role=listbox] · data-jello-height

    ‘말’이나 ‘라’를 쳐 보세요. search도 글자를 치는 입력칸이라 한 글자마다 흔들리고, 지우기는 버튼이라 눌려요.

    추천 목록에는 data-jello-height 하나만 붙였어요. 앱은 li를 넣고 빼기만 하고, 높이는 jello가 스프링으로 따라와요. 위아래 화살표로 고르고 엔터로 넣고, Esc로 닫아요.

    슬라이더

    input[type=range] · 놓을 때

    빠르게 끌다가 놓으면 그 방향으로 밀려났다 돌아와요. 멈추고 놓으면 밀리지 않아요.

    체크박스 · 라디오

    change

    켤 때 더 크게, 끌 때 작게 통통 튀어요.

    스위치

    [role=switch] · aria-checked

    야간 배송직접 만든 스위치 · aria-checked

    손잡이가 움직이는 건 CSS 전환이고, 스위치 전체가 통통 튀는 건 jello예요. 둘 다 같은 스프링을 써요.

    토글 칩

    aria-pressed

    누르는 반응과 상태가 바뀐 반응이 겹쳐요. 끌 때는 조금 작게 튀어요.

    세그먼트

    input[type=radio] · change

    라디오를 숨기고 칸만 보여요. 좌우 화살표로도 바뀌어요.

    별점

    숨은 input → 보이는 요소

    input이 눈에 안 보이면 바로 옆의 보이는 요소가 대신 움직여요. 누른 별 하나만 튀어요.

    리스트박스

    [role=option] · aria-selected

    라즈베리
    라임
    살구
    블루베리

    aria-selected가 true가 된 항목만 튀어요. 빠진 쪽은 조용해요. 위아래 화살표로도 옮겨요.

    탭

    [role=tab] · aria-selected · data-jello-indicator

    라즈베리, 라임, 살구, 블루베리 네 가지예요.

    젤라틴 2%면 말랑, 4%면 탱글해요.

    한 컵에 약 70kcal예요.

    고른 탭 뒤의 판이 미끄러져 따라와요. 앱은 aria-selected만 바꾸고, 판에는 data-jello-indicator 하나만 붙였어요. 왼쪽 목록도 같은 코드예요.

    세로 탭

    aria-orientation="vertical"

    4℃에서 사흘쯤 가요. 물이 조금 빠지면서 탱글해져요.

    얼리면 젤라틴 그물이 끊어져서, 녹은 뒤엔 흐물흐물해져요.

    28℃가 넘으면 녹아요. 젤라틴은 체온 근처에서 풀려요.

    위아래 화살표로 옮겨요. 가로일 때는 넓이를, 세로일 때는 높이를 탭에 맞춰요.

    아코디언

    <details>

    젤리는 왜 흔들릴까요?

    젤라틴 그물 속에 물이 갇혀 있어서, 눌렸다 놓이면 탄성으로 돌아가며 몇 번 출렁여요. 스프링과 같은 원리예요.

    냉장고에 오래 두면요?

    물이 빠져나와 단단해지고 덜 흔들려요. bounce를 낮춘 firm 프리셋과 비슷해요.

    몇 번까지 출렁여요?

    bounce 0.65면 두 번 정도 눈에 보이게 출렁이고, 0.75면 서너 번이에요. 아래 직접 조절하기에서 바꿔 볼 수 있어요.

    제목은 가만히 있고 내용만 떨어지듯 열려요. 세 개는 name으로 묶여 한 번에 하나만 열려요.

    커스텀 아코디언

    [aria-expanded][aria-controls]

    aria-expanded와 hidden만 바꾸면 aria-controls로 연결된 패널이 떨어지듯 열려요. details와 똑같이 움직여요.

    aria-haspopup이 붙어 있으면 아코디언이 아니라 메뉴로 보고, 패널 대신 버튼이 살짝 튀어요. 위의 검색 입력칸이 그 경우예요.

    페이지네이션

    button · aria-current="page"

    jello는 aria-current를 보지 않아요. 여기 움직임은 버튼을 누른 반응 하나예요. 화살표로 옮긴 쪽은 조용해요.

    메뉴

    [popover]

    팝오버가 열릴 때 0.85 크기에서 튀어나와요. 안의 항목은 각각 눌려요.

    팝오버는 화면 맨 위 층에 떠서 페이지 좌표를 모르기 때문에, 버튼 아래 자리는 앱이 잡아 줘요. 아래가 좁으면 위로 뒤집혀요.

    대화상자

    <dialog>

    젤리를 비울까요?

    장바구니에 담긴 젤리 3개가 사라져요.

    open이 붙는 순간 0.9 크기에서 튀어나와요. 비우기를 누르면 토스트까지 이어져요.

    툴팁

    [popover] · role=tooltip

    콜라겐에서 뽑은 단백질이에요. 물을 가두는 그물을 만들어서 젤리가 흔들려요.

    메뉴와 같은 팝오버 경로예요. 자리를 잡는 코드도 메뉴와 같은 한 줄을 써요. 마우스를 올려 띄우고 싶으면 앱에서 직접 열고 닫아야 해요.

    토스트

    data-jello-enter

    DOM에 추가될 때 적어 둔 크기에서 튀어나와요. 화면 아래에 떠요.

    배지

    pop() · hop()

    0

    속성이 아니라 코드로 부르는 쪽이에요. 처음 나타날 때 pop({ from: 0 }), 숫자가 바뀔 때 pop(), 종은 hop()이에요.

    오류

    invalid · aria-invalid

    빈칸이나 다섯 글자가 아니면 브라우저가 invalid를 띄우고, 그때 흔들려요. 앱이 aria-invalid="true"를 붙여도 같아요.

    디자인 토큰

    색이나 간격은 그대로 지나가고, 스프링은 CSS 변수가 돼요. 같은 곡선을 JS 애니메이션과 손으로 쓴 transition이 함께 써요.

    이 버튼에는 data-jello가 없어요. 토큰이 만든 --demo-motion-press 하나로 CSS만 써서 눌려요.

    쓴 코드
    import { spring, tokens } from 'jello'

const theme = tokens({
  color: { jelly: '#d7264f', ink: '#ffffff' },
  motion: { press: spring({ duration: 0.5, bounce: 0.6 }) },
}, { prefix: 'demo', dark: { color: { jelly: '#e83a63' } } })
