data-jello="firm | gentle | wobbly | bouncy"

네 가지 탄력

%는 손을 뗀 뒤 반대쪽으로 튀어 오르는 정도예요.

firm

돈이 오가는 버튼처럼 진지한 곳. 단단하게 눌리고 거의 튀지 않아요.

gentle

평범한 버튼. 한 번 부드럽게 늘어났다 멈춰요.

wobbly기본값

젤리답게 두 번 출렁여요.

bouncy

좋아요나 스티커처럼 노는 버튼. 서너 번 흔들려요.

컴포넌트

상자에 data-jello를 붙이면 안의 컨트롤이 종류에 맞게 반응해요. 네이티브 요소와 ARIA 상태를 그대로 써요.

입력 focus · input · invalid

이메일을 비우고 가입하기 → 흔들림. 탭 키로 이동 → 살짝 부풂.

선택 change · aria-checked · aria-pressed

야간 배송직접 만든 스위치 · aria-checked

슬라이더 input · 놓을 때

빠르게 끌다가 놓으면 그 방향으로 밀려났다 돌아와요.

탭 aria-selected

라즈베리, 라임, 살구, 블루베리 네 가지예요.

젤라틴 2%면 말랑, 4%면 탱글해요.

한 컵에 약 70kcal예요.

아코디언 details · aria-expanded

젤리는 왜 흔들릴까요?

젤라틴 그물 속에 물이 갇혀 있어서, 눌렸다 놓이면 탄성으로 돌아가며 몇 번 출렁여요. 스프링과 같은 원리예요.

냉장고에 오래 두면요?

물이 빠져나와 단단해지고 덜 흔들려요. bounce를 낮춘 firm 프리셋과 비슷해요.

몇 번까지 출렁여요?

bounce 0.65면 두 번 정도 눈에 보이게 출렁이고, 0.75면 서너 번이에요. 위의 직접 조절하기에서 바꿔 볼 수 있어요.

aria-expanded와 hidden만 바꾸면 aria-controls로 연결된 패널이 떨어지듯 열려요.

위의 세 개는 name으로 묶여 한 번에 하나만 열려요.

코드로
import { jello, shake, pop, hop } from 'jello'

const buy = jello('#buy', { preset: 'firm', tilt: 0 })
shake(passwordField)      // 틀렸을 때
pop(badge)                // 숫자가 바뀔 때
pop(toast, { from: 0 })   // 나타날 때
hop(cartIcon)             // 담겼을 때
buy.destroy()
